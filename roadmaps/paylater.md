# Pay-later Tracker — roadmap

**Status:** idea · works alongside Klarna, Clearpay and Zilch (those stay)

Every buy-now-pay-later plan in one place, so nothing due sneaks up.

## Phase 1
- [ ] Add a plan: provider, what it was for, total, number of instalments, first date, frequency
- [ ] Calendar and list of upcoming instalments across all providers
- [ ] Total due this week, this month and next month
- [ ] Tick instalments paid; plan closes when the last one is ticked
- [ ] Export / import in the shared backup envelope; CSV
- [ ] Repo, Pages, PWA shell

## Phase 2
- [ ] Read payment-confirmation emails to fill plans in (needs care: only on request, never stored off the phone)
- [ ] A heads-up the day before a payment, if notifications can be made reliable
