# Home Rounds — roadmap

**Status:** idea · **Replaces:** Chorefriend

Rounds, pointed at the flat: repeating household chores, grouped by room, shared out.

## Phase 1
- [ ] Copy Rounds' engine into a new repo
- [ ] Rooms and chores, each with a repeat (daily, set weekdays, every N days, monthly)
- [ ] Today view: what's due and what's overdue, tick to done
- [ ] Export / import in the shared backup envelope

## Phase 2
- [ ] People on each chore and a rota that rotates who's next (Chorefriend)
- [ ] Simple jobs the girls can tick, with a sticker or star

## Open question
- Sharing between phones: local-only means one phone holds the list. Options are a shared
  family tablet, or a sync through your own Google Drive later. Decide before Phase 2.
